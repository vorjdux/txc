# age test vectors for `mlkem768x25519`

Copied from [C2SP/CCTV](https://github.com/C2SP/CCTV/tree/main/age/testdata),
the Community Cryptography Test Vectors, whose license allows copying them
without attribution. They were generated by the reference implementation,
Go age 1.3, and check that txc's post-quantum recipient (`src/vault/pq.rs`)
reads exactly what Go age writes and refuses exactly what it refuses.

`hybrid_multiple_recipients` is left out because it is zlib-compressed and
reading it would need a decompressor for this one file.
